# Code of conduct

## The short version

Be decent. Assume the other person is trying to build something good.

## What is expected

- Argue with the work, not the person.
- Report a bug the way you would want one reported to you: what you expected,
  what happened, and the smallest thing that reproduces it.
- When you are wrong, say so and move on. This repository has a 53-entry file
  of the maintainer being wrong; nobody here is above it.

## What is not

Harassment, personal attacks, discriminatory language, or deliberately wasting
someone's time. Publishing a security issue publicly before it is fixed, when
`SECURITY.md` tells you how to report it privately.

## Attacks are welcome. Attacking people is not.

REMIT actively invites people to break it, and a working attack is the most
valuable contribution you can make. That is about the software.

## Enforcement

Report anything to the maintainer through a private GitHub security advisory or
by opening an issue if it is not sensitive. Behaviour that persists after being
raised gets the person blocked from the repository.
